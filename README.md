# Estonian language passphrase generator. version 2.0 2026

* Improved xkcd style (http://xkcd.com/936/) passphrase generator
* Based on Estonian diceware wordlist (ASCII only, no diacritics): https://täringvara.ee/
* Configurable: word count (3–6), separator, special characters, max length — settings saved in cookie
* Uses `crypto.getRandomValues()` for cryptographically secure randomness
* v1.0 was generated by ChatGPT. v2.0 rebuilt with Claude and manual editing.
* Demo: https://parool.biker.ee/
* Inspiration: https://rabool.eu/
